# MoneyCraft

**MoneyCraft** is the sovereign financial intelligence terminal, anti-scam smart contract auditor, and quantitative algorithmic backtesting studio for the sandraschi fleet.

## Key Capabilities
- **Anti-Scam Honeypot Engine**: Sandbox EVM simulation exposing hidden transfer taxes (>5%), blacklist traps, and unrenounced mint backdoors.
- **Microsecond Event-Driven Backtesting**: 10,000-path Monte Carlo simulations calculating Sharpe, Sortino, max drawdown, and probability of ruin.
- **Sovereign Private Portfolio Ledger**: Built-in FIFO/LIFO tax calculations powered by local **DatabaseCraft** B-Trees with zero data telemetry.
- **Universal 3-Tier ArtCraft Standard**:
  - `crates/moneycraft-feed`: Market ticker feeds, orderbook level-2/3 streams, and sandbox EVM.
  - `crates/moneycraft-core`: Quantitative risk metrics, execution fences, and Command Bus (`Command::dispatch`).
  - `crates/moneycraft-mcp`: Line-delimited MCP stdio server + CLI (`moneycraft-cli`).
  - `crates/moneycraft-app`: Immediate-mode native desktop financial terminal (`moneycraft`).
- **Standard Control Port**: `14117`.
